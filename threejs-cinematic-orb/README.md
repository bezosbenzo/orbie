# Cinematic Orb

Interactive kinetic 3D sculpture built in a single HTML file using Three.js.

## Features
- Metallic iridescent orb and three orbiting rings
- Colored cinematic lighting and atmospheric particles
- Mouse orbit, scroll zoom, responsive layout
- No build step required

## Run locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000. Internet access is required to load Three.js from jsDelivr.

## Stack
HTML, CSS, JavaScript, Three.js (CDN).
